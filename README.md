# Сайт-портфолио — Иван Демидов

Один самодостаточный файл `index.html`: вся вёрстка, стили и скрипты внутри.
Сборка не нужна — файл открывается двойным кликом и работает без сервера.

## Структура

```
portfolio-site/
├── index.html            ← сам сайт (единственный файл, который правим)
├── resume.pdf            ← ПОЛОЖИ СЮДА резюме (кнопка «Скачать резюме» ссылается на него)
└── assets/
    ├── photos/           ← фото, уже сжатые в WebP (не трогай без нужды)
    └── docs/             ← СЮДА кидай документы, ТЗ, презентации, отчёты
```

## Куда что класть

- **Резюме** → `Demidov_Ivan_Sport_Manager_CV.pdf` в корне. Если заменишь файл на новую версию
  с другим именем — поправь `href` у кнопки «Скачать резюме» в секции `#contact`.
- **Отзыв ФНЛ** лежит НЕ на сайте, а в `~/.claude/portfolio/_private/fnl-recommendation.pdf`.
  На сайте вместо него форма запроса: человек оставляет имя, компанию и контакт,
  кнопка открывает почтовый клиент с готовым письмом на `ivandemidov18@icloud.com`.
  Ты решаешь, кому отправить файл. Не клади его обратно в `assets/docs/` — иначе он
  станет доступен всем по прямой ссылке.

- **Документы** → `assets/docs/`. Там уже лежат 17 файлов из папки `~/.claude/portfolio`,
  переименованные в латиницу (кириллица в URL ломается при публикации). Каждый выведен
  в разделе «Материалы» с типом и размером. Добавляешь новый файл — не забудь добавить
  строку в разметку раздела `#docs` и подписи в оба блока словаря.
- **Новые фото** → присылай оригиналы, они прогоняются через сжатие и кладутся в `assets/photos/`.

## Локальный просмотр

Двойной клик по `index.html`. Либо, если нужен нормальный сервер:

```bash
cd ~/portfolio-site && python3 -m http.server 8000
# → http://localhost:8000
```

## Как что-то поменять

Весь сайт — один файл `index.html`. Ничего собирать не нужно: правишь, сохраняешь, обновляешь страницу.

**Цвета.** Все до единого лежат в блоке `:root` в начале `<style>`. Меняешь одну строку — меняется весь сайт.

```css
--accent: #4fe8c4;   /* акцент — только главное действие, критичное число, ошибка */
--bg:     #08080c;   /* фон страницы */
--fg:     #f2f3f5;   /* основной текст */
```

Акцент намеренно один и появляется всего в трёх ролях: кнопки главного действия,
цифры в первом экране, метки `[TODO]`. Всё остальное монохромное — так дороже
и так работает иерархия. Если начнёшь красить акцентом заголовки, иконки и рамки,
эффект пропадёт.

**Стекло.** `backdrop-filter` стоит только на липкой шапке и мобильной шторке —
там под ним реально проезжает контент. На карточках его нет намеренно: это дорогой
способ нарисовать серый прямоугольник, и он пересчитывается каждый кадр.

**Шрифты.** Unbounded (заголовки) + Golos Text (текст), подключены с Google Fonts одной строкой в `<head>`.
Заменить — поменять `<link>` и токены `--font-display` / `--font-body`.

**Тексты.** Каждый текстовый узел помечен `data-i18n="ключ"`, а сами тексты — в объекте `i18n`
в конце файла: сначала блок `ru`, следом `en`. Правишь текст — правь в обоих блоках,
иначе при переключении языка ключ разъедется.

**Отступы, радиусы, скорость анимаций** — тоже токены в `:root`.

## Публикация на GitHub Pages

```bash
cd ~/portfolio-site
git init && git add . && git commit -m "Портфолио: первая версия"
gh repo create <имя-репозитория> --public --source=. --push
# затем в настройках репозитория: Settings → Pages → Branch: main / root
```

`.gitignore` уже настроен — служебные папки `.omc/` и `.impeccable/` в репозиторий не попадут.

После публикации подставь боевой адрес в `index.html`
в теги `og:url`, `og:image` и `twitter:image` (сейчас там заглушка `https://example.com/`).
